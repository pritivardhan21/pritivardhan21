## 🧠 Featured Engineering Work

### 🛡️ NetDefender — SDN-Based Zero-Day Threat Detection, Throttling & Honeypot Redirection
> Solo project · 2026 Formosa Talent Internship Program (FTIP), National Formosa University · **Graded 91/100 (top band in cohort)**

A Software-Defined Networking defense system that detects zero-day threats in real time, throttles malicious traffic before it reaches protected hosts, and redirects attackers into a honeypot to turn live attacks into reusable threat intelligence. Built end-to-end, alone — from the SDN controller logic to the deception layer.

- Built the detection pipeline on the **Ryu controller**, dynamically rewriting flow rules to isolate anomalous traffic in real time.
- Engineered an **adaptive throttling** layer that degrades malicious throughput while leaving legitimate traffic untouched.
- Designed a **Docker-based honeypot** deception network and tracked attacker behavior inside isolated environments.

**Tech:** Python · Ryu Controller · Docker · Software-Defined Networking (SDN)
